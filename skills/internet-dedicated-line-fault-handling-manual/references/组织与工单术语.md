# 组织与工单术语

依据工作区 `my_skill-clean/skills/internet-dedicated-line-fault-handling/references/组织与工单术语.md` 整理，保留原版组织职责和工单规则，将随单“结构化查询结果”改为适合手动版的命令、原始回显或截图。不要求原版目录存在即可使用。

本参考用于判断故障应由哪个组织或岗位继续处理，以及是否可以派单、加派或挂单。组织归属以工单中的客户所在地、接入地市和设备归属为准；信息不足时不得擅自指定地市或岗位。以下为本技能采用的内部口径，不外推为其他地区或单位的规则。

## 工单系统和动作

- **服保**：服务保障系统，也是工单系统。所有工单在服保中流转和管控。
- **派单/加派**：将手中的工单加派给指定岗位。输出建议时应写清“派给谁、做什么、为什么派”，而不是只写“通知相关人员”。
- **挂单**：因客观情况暂时无法处理，暂停工单计时。挂单必须是非电信原因，例如客户不在、客户已下班等；必须提供挂单时长，并保留录音、聊天记录等能够证明原因和时间的证据。

以下情况不得作为挂单理由：

- 电信网络、设备、线路、资源或系统异常；
- 电信侧人员不足、排班或内部等待；
- 等待派单、等待其他岗位处理或工单流转缓慢；
- 尚未完成必要排查，无法说明真实的非电信原因。

如需建议挂单，应同时列出：

1. 非电信原因及责任边界；
2. 挂单开始和结束时间（或明确时长）；
3. 录音、聊天记录或其他证据是否已取得；
4. 恢复处理的触发条件。

证据或时间信息不完整时，建议“补充证据后再挂单”，不要直接建议挂单。AI只给建议，不能声称已派单、已挂单或已暂停计时；服保实际操作和状态由操作人确认。

## 湖南本地网组织

以下为湖南十四个地市分公司：

长沙市、株洲市、湘潭市、衡阳市、邵阳市、岳阳市、常德市、张家界市、益阳市、郴州市、永州市、怀化市、娄底市、湘西州分公司。

各地市分公司下设与本技能相关的岗位：

- **政支**：政企支撑相关岗位，按本地网安排客户侧支撑和现场协同。
- **装维**：负责上门服务客户、现场查障和客户侧配合。
- **网操**：负责OLT层面的操作。

派本地网时按处理动作选择岗位：

- 需要上门、现场查线、客户侧测试、客户配合或现场观察：派地市分公司 **政支/装维**；
- 需要OLT查询以外的现场协同，且由本地网执行：仍应说明由 **政支/装维** 配合；
- 明确需要OLT层面操作：派对应地市分公司 **网操**；
- 仅凭“设备异常”无法判断现场还是OLT操作时，先补充证据，不要笼统派“装维”或“网操”。

## 省公司直属单位和中心

- **客支中心**：当前接维单位，是地市政支的上级单位、省公司直属单位，负责预处理。只有需要本地网（各地市分公司）上门或配合时，才由客支中心发起对本地网的派单；不因内部等待直接派本地网。
- **客支中心 - 工单室**：负责工单管控。涉及服保流转、工单状态、超时风险、派单协调或异常管控时，可建议加派/升级至工单室；工单室不是现场查障或设备操作岗位。
- **云网调度中心**：负责MSE、SR、CR、D等关键设备以及传输设备的操作与维护。证据指向这些设备或传输链路时，优先建议派/加派云网调度中心，不要派本地装维代替处理。

上述关系只覆盖原版明确的组织和岗位，不据此推断云网调度中心等单位之间未说明的上下级关系。

## 故障证据到派单方向

| 证据或所需动作 | 建议方向 |
| --- | --- |
| 客户侧、末端线路、光纤、现场电源、入户设备，需要到场确认 | 对应地市分公司政支/装维 |
| OLT端口、ONU注册/状态、OLT侧业务或端口操作 | 对应地市分公司网操；仅有光路/供电线索需到场确认时按上一行处理 |
| MSE、SR、CR、D或传输设备告警、接口、路由或链路处理 | 云网调度中心 |
| 工单状态、派单协调、超时/流转风险、服保管控 | 客支中心 - 工单室 |
| 当前证据不足以确定归属 | 客支中心继续预处理，先补充查询或信息，不直接派单 |

表格只提供方向，不替代设备命令手册或生产操作授权。涉及具体配置、刷新、重启或其他生产操作时，仍须引用已审核的命令或步骤，并由人工通过4A执行和留痕。

原版没有明确AAA归属岗位；按实际归属核实后建议派单，不自动归给网操或云网调度中心。CR、D等设备缩写保留原文，未提供内部释义时不自行扩写；本手动版也不因此新增这些设备的查询或操作命令。

## 派单建议的最小字段

在“派单或升级建议”中按以下顺序填写；无需派单时写“无”，不要为填写栏目强行选择部门：

- **目标组织/地市**：例如“衡阳市分公司”，地市未知时明确标注待确认；
- **目标岗位**：政支/装维、网操、云网调度中心或客支中心-工单室；其他岗位须有实际归属依据；
- **派单/加派动作**：上门查障、现场配合、OLT操作、关键设备/传输处理或工单管控；
- **派单依据**：引用告警、端口、光功率、链路、现场反馈、时间线等具体证据；
- **随单材料**：查询命令及原始回显/截图、故障现象、客户联系人和可联系时间、现场照片/测试记录等；敏感凭据不得提交；
- **挂单状态**：仅在满足非电信原因和证据要求时填写建议挂单，否则写“不涉及/不可挂单/证据不足”并说明原因。

随单材料指在获准的内网服保工单中保留。客户联系方式、录音、聊天记录等不要求上传公网AI；由操作人确认材料是否齐备，必要时仅提供获准脱敏摘要。
