# 质量参照标准

检查OLT、ONU的光信息时，用本文件对照已查询到的指标。当前仅收录PON相关标准，PON之外后续补充。

## PON光信息

来源：用户提供的《光衰整治派单规则》截图，标注更新日期为2026-08-07。

| 制式 | 方向 | 光衰阈值 | 收光阈值 |
| --- | --- | --- | --- |
| EPON | 上行 | ≥ 30 dB | PON口收光 ≤ -25 dBm |
| EPON | 下行 | ≥ 28 dB | 光猫收光 ≤ -23 dBm |
| GPON | 上行 | ≥ 32 dB | PON口收光 ≤ -28 dBm |
| GPON | 下行 | ≥ 30 dB | 光猫收光 ≤ -26 dBm |

## 使用方法

- 按实际EPON/GPON制式和上下行方向选择对应行，对照当前查询对象的实测值。
- 上行收光看OLT侧PON口接收该ONU的光；下行收光看光猫/ONU接收的光。光衰用dB，收光功率用dBm，不混用。
- 同一行两项条件为“或”，任一项达到即标注该项达到异常阈值；等于阈值也计入。
- 查到什么就对照什么，在判断依据中写“指标、实测值、参照阈值、对照结果”。未取得的指标注明未采集，不要求先补齐所有光指标才能继续排查。
- 制式、方向、单位或数值不明确时不硬套阈值；表中未提供独立发光功率阈值，不自行补充。
- 对照结果作为现有排查判断的依据，后续操作和派单沿用原流程，不另设流程。
