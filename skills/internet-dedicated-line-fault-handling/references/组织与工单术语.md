# 组织与工单术语

本参考用于判断故障应由哪个组织或岗位继续处理，以及是否可以派单、加派或挂单。组织归属以工单中的客户所在地、接入地市和设备归属为准；信息不足时不得擅自指定地市或岗位。

## 工单系统和动作

- **服保**：服务保障系统，也是工单系统。所有工单在服保中流转和管控。
- **派单/加派**：将手中的工单加派给指定岗位。输出建议时应写清“派给谁、做什么、为什么派”，而不是只写“通知相关人员”。
- **挂单**：因客观情况暂时无法处理，暂停工单计时。挂单必须是非电信原因，例如客户不在、客户已下班等；必须提供挂单时长，并保留录音、聊天记录等能够证明原因和时间的证据。

以下情况不得作为挂单理由：

- 电信网络、设备、线路、资源或系统异常；
- 电信侧人员不足、排班或内部等待；
- 等待派单、等待其他岗位处理或工单流转缓慢；
- 尚未完成必要排查，无法说明真实的非电信原因。

如需建议挂单，应同时列出：

1. 非电信原因及责任边界；
2. 挂单开始和结束时间（或明确时长）；
3. 录音、聊天记录或其他证据是否已取得；
4. 恢复处理的触发条件。

证据或时间信息不完整时，建议“补充证据后再挂单”，不要直接建议挂单。

## 湖南本地网组织

以下为湖南十四个地市分公司：

长沙市、株洲市、湘潭市、衡阳市、邵阳市、岳阳市、常德市、张家界市、益阳市、郴州市、永州市、怀化市、娄底市、湘西州分公司。

各地市分公司下设与本技能相关的岗位：

- **政支**：政企支撑相关岗位，按本地网安排客户侧支撑和现场协同。
- **装维**：负责上门服务客户、现场查障和客户侧配合。
- **网操**：负责 OLT 层面的操作。

派本地网时按处理动作选择岗位：

- 需要上门、现场查线、客户侧测试、客户配合或现场观察：派地市分公司 **政支/装维**；
- 需要 OLT 查询以外的现场协同，且由本地网执行：仍应说明由 **政支/装维** 配合；
- 明确需要 OLT 层面操作：派对应地市分公司 **网操**；
- 仅凭“设备异常”无法判断现场还是 OLT 操作时，先补充证据，不要笼统派“装维”或“网操”。

## 省公司直属单位和中心

- **客支中心**：当前接维单位，是地市政支的上级单位、省公司直属单位，负责预处理。基本定位客户侧或需要本地网（各地市分公司）上门/配合时派本地网；设备处理超出当前权限时按归属派有权限岗位。
- **客支中心 - 工单室**：负责工单管控。涉及服保流转、工单状态、超时风险、派单协调或异常管控时，可建议加派/升级至工单室；工单室不是现场查障或设备操作岗位。
- **云网调度中心**：负责 MSE、SR、BRAS、CR、D 等关键设备以及传输设备的操作与维护。当前接维岗位对MSE/SR/BRAS只有查看权限，需要设备处理时派/加派云网调度中心，不派本地装维代替操作。

## 故障证据到派单方向

| 证据或所需动作 | 建议方向 |
| --- | --- |
| 已有关键证据基本定位客户侧，或末端线路、光纤、现场电源、入户设备需要到场确认 | 对应地市分公司政支/装维 |
| OLT 端口、ONU 注册/状态、OLT 侧业务或端口操作 | 对应地市分公司网操 |
| MSE、SR、BRAS、CR、D 或传输设备告警、接口、路由或链路处理 | 云网调度中心 |
| 必要查询被拒绝，或下一步处理超出当前岗位权限 | 按设备/系统归属派有权限岗位，附已查证据、权限缺口和接手事项 |
| 工单状态、派单协调、超时/流转风险、服保管控 | 客支中心 - 工单室 |
| 尚不能定位或确定接手岗位，且仍有权限补查 | 仅补影响结论的关键查询或归属信息，不查遍全部设备 |

表格不扩展操作权限。MSE/SR/BRAS仅能查看，变更交云网调度中心；其他设备操作也须当前岗位已有权限并使用已审核步骤，通过4A执行和留痕。派单时说明收敛原因，不把已派单写成已修复。

## 派单建议的最小字段

在固定输出的“派单或升级建议”栏目中，尽量按以下顺序填写：

- **目标组织/地市**：例如“衡阳市分公司”，地市未知时明确标注待确认；
- **目标岗位**：政支/装维、网操、云网调度中心或客支中心-工单室；
- **派单/加派动作**：上门查障、现场配合、OLT 操作、关键设备/传输处理或工单管控；
- **派单依据**：引用告警、端口、光功率、链路、现场反馈、时间线等具体证据；
- **随单材料**：结构化查询结果、故障现象、客户联系人和可联系时间、现场照片/测试记录等；敏感凭据不得提交；
- **挂单状态**：仅在满足非电信原因和证据要求时填写建议挂单，否则写“不可挂单/证据不足”。
