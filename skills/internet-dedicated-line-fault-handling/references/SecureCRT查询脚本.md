# SecureCRT 查询脚本

当前接维岗位对MSE/SR/BRAS只有查看权限，采集脚本不承担配置修改、清表、刷新、强制下线或重启。基本定位客户侧或后续查询/处理无权限时，停止追加采集，整理已有结果派相应岗位。BRAS查询须有已确认适配的手册/脚本，不直接按名称套用MSE/SR入口。

`scripts/` 中的脚本按厂家和设备类型拆分：

| 文件 | 厂家 | 设备类型 |
| --- | --- | --- |
| `huawei_mse.py` | 华为 | MSE |
| `zte_mse.py` | 中兴 | MSE |
| `h3c_mse.py` | 华三 | MSE |
| `huawei_sr.py` | 华为 | SR |
| `zte_sr.py` | 中兴 | SR |
| `h3c_sr.py` | 华三 | SR |
| `huawei_olt.py` | 华为 | OLT |
| `zte_c600_olt.py` | 中兴 | C600 OLT |
| `zte_c300_olt.py` | 中兴 | C300 OLT |
| `fiberhome_an6000_olt.py` | 烽火 | AN6000 OLT |
| `fiberhome_an5000_olt.py` | 烽火 | AN5000 OLT |

MSE的三个入口脚本均为独立单文件，可直接复制并通过 SecureCRT 的“脚本 > 运行”执行，不依赖其他文件。SR和OLT入口脚本仍需与 `securecrt_query_common.py` 放在同一目录。

MSE脚本启动后先依次收集用户名、用户IP地址和用户MAC地址，三者至少填写一项。脚本根据已填写的信息自动执行对应的在线状态、上线失败记录和下线记录查询。命令参考没有提供按IP查询失败或下线记录时，只执行按IP查询在线状态。

脚本只运行查询命令，不进入配置模式。执行前需输入设备命令行提示符，脚本通过该提示符判断一条命令是否执行完毕；提示符必须与设备实际回显完全一致。查询结果默认保存到当前 Windows 用户桌面，也可在保存对话框中修改路径。

输出包含采集信息、查询对象、逐项命令回显、执行失败项和脚本规则提示，可直接提交给本 skill 继续分析。

华为OLT、烽火AN6000和烽火AN5000的部分参考命令需要进入设备子视图。这些脚本一次只执行一个查询项目，并且不会编造退出命令；采集结束后应人工核对当前视图并返回原视图。烽火AN5000上联口查询的参考资料只给出了 `Admin\\interface#` 下的查询命令，因此需要人工预先进入该视图。

## 命令来源说明

所有设备查询命令来自用户提供的 MSE/SR 命令参考。参考表内中兴 ARP 命令的 `nterface` 明显缺少首字母，脚本按 `interface` 修正。未在参考表中提供的中兴 SR 子接口配置、直连路由过滤和静态路由过滤命令没有补充，以避免生成未经确认的生产网命令。
